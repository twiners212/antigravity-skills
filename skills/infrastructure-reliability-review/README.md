# Infrastructure Reliability Review

An Antigravity skill for evidence-based infrastructure, CI/CD, reliability, bottleneck, and pre-incident risk reviews.

## Install in one workspace

Copy this folder into your project's:

```text
<project-root>/.agents/skills/infrastructure-reliability-review/
```

The required file is `SKILL.md`.

## Install globally

Copy this folder into:

```text
~/.gemini/config/skills/infrastructure-reliability-review/
```

## Invoke

Use the slash command:

```text
/infrastructure-reliability-review
```

Or ask Antigravity to review the infrastructure, CI/CD pipeline, reliability risks, and likely bottlenecks; the skill description is designed for automatic discovery too.

The skill defaults to read-only inspection and requires explicit authorization for changes or production-impacting tests.
